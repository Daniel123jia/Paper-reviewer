# P3 审稿任务与候选问题实施计划

## 目标

用户能创建一审、本人复审或新增审稿人任务，关联原稿、修订稿及作者回复；系统从真实 PDF 证据提出少量候选问题，再由独立模型调用寻找反证。每条问题记录原文位置、证据等级、验证状态和反证说明。P3 的 AI 复核不视为数学证明；需要计算或独立推导的问题留给 P4。

## 步骤与验收

1. 审稿任务与材料关系：测试三种模式及材料约束；实现 SQLite 与 API。验收：任务和关联文档重启后仍可读取。
2. 候选问题与反证：先测试证据 ID 校验、验证状态和无充分证据的降级；再接入中转站两次真实调用。验收：原文引用可解析，复核保留反证和不确定性，不自动宣称数学错误。
3. 网页工作流：增加任务创建、分析进度、问题卡片与证据跳转。验收：真实 PDF 浏览器测试覆盖创建、运行、查看证据和刷新恢复。
4. 跑后端测试、前端构建和浏览器验收；记录模型、Token、耗时、失败和未完成项。
