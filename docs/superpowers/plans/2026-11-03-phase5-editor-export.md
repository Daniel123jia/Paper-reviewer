# P5 审稿文档与导出实施计划

1. 建立两种独立草稿模板：完整内部审稿报告保留候选、反证、技术检查及证据附录；正式审稿意见只纳入独立复核支持的待澄清问题，不把未验证数学疑点写成错误。验证：真实审稿任务产出内容与状态一致。
2. 草稿按任务、类型和语言保存，可在网页编辑。英文版通过明确标注消耗 Token 的翻译调用生成，核对 Evidence ID 和数字不丢失。验证：刷新恢复修改和用量记录。
3. Markdown 原样导出；Pandoc 将 Markdown 表格和 LaTeX 转成可编辑 DOCX，两个文档类型使用独立 Word 样式模板；Pandoc 生成含 MathML 的 HTML，再由 Playwright Chromium 排版成 PDF。最初 LibreOffice 转 PDF 的中文字体映射失败，已按实际页图检查结果改用 Chromium。验证：中英文 DOCX/PDF 能打开，公式、表格、页码、字体和分页检查。
4. 用真实 5 页论文及已有审稿任务运行浏览器编辑与下载，检查导出文本和 PDF 页面截图，修复排版问题，记录 P5 验收与部署依赖。
