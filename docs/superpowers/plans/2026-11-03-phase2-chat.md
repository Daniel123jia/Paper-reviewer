# Phase 2 Evidence Chat Implementation Plan

**Goal:** Stream real AI answers grounded in retrieved PDF evidence, preserve multi-turn history and link citations to P1 reader.

**Architecture:** FastAPI owns conversation storage, retrieval, model calls and SSE. React renders Markdown and math, shows messages and links validated evidence IDs. PDF files stay in local private storage.

**Tech Stack:** FastAPI, SQLite, OpenAI-compatible Chat Completions streaming API, React, react-markdown, remark-math, rehype-katex, Playwright.
