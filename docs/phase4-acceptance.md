# P4 技术与数学验证本地验收（2026-11-03）

## 本阶段实际实现

- 从 PDF 文字块中识别明确的“拆分/改写公式 (n)”描述，并关联相邻编号的两处公式及关系说明的 Evidence ID。真实样例自动得到公式 (4) → (5)；关联线索不等于等价证明。
- 在任务内选择两处原文证据，运行受限表达式解析、SymPy 化简和确定性 NumPy 数值反例。保存表达式、假设、工具版本、原文引用与结果；原文转录状态保持 `unconfirmed`。
- 对可明确解析的并行矩阵乘法说明推导输入、输出维度和总输出元素数。真实论文两条路径分别得到 `b*h*n**2`；这不能证明训练内存或论文的整体空间复杂度公式。
- 对明确标注 Absolute / Relative、EN-DE / EN-FR、base / big 的成对 BLEU 表格，将四个表格差值与正文四项提升声明逐一核对。真实论文四项一致；其他格式返回无法解析，不做猜测。
- 对已有候选问题从整篇材料重新检索相关块，保留原引用，进行独立模型反证。二审材料中会至少保留原稿、修订稿和作者回复各一处文字块。复核结果保存有效 Evidence ID、支持关系、反证、缺失检查和用量；不会仅凭模型意见把数学疑点提升为已证实错误。

## 真实论文结果

样例为《Self-Attention with Relative Position Representations》5 页 PDF。

- 公式 (4) 第 2 页 `ev_c1c08dc5e672_1_19` 与公式 (5) 第 3 页 `ev_c1c08dc5e672_2_19` 自动关联。标量化关系 `q*(k+a)/sqrt(d)` 与 `(q*k+q*a)/sqrt(d)` 在 `d>0` 下化简差为 0；故意漏掉 `q` 得到可重复的数值反例，界面仍明确标注 PDF 转录未确认。
- 第 3 页两段算法描述 `ev_c1c08dc5e672_2_18`、`ev_c1c08dc5e672_2_24` 的矩阵乘法内维度相容，输出元素总数都为 `b*h*n**2`。
- 第 4 页 Table 1 `ev_c1c08dc5e672_3_0` 与正文结论 `ev_c1c08dc5e672_3_2`：EN-DE base `26.8−26.5=0.3`、big `29.2−27.9=1.3`；EN-FR base `38.7−38.2=0.5`、big `41.5−41.2=0.3`，与正文一致。
- 原有“整体自注意力空间复杂度统计范围”候选问题经扩展检索，从 99 个文字块中选 20 个，模型引用 5 个有效 Evidence ID，结果为 `supported_clarification`：原文支持要求澄清统计口径，但不足以确认复杂度公式错误。一次真实调用记录 `gpt-6.1-sol` 输入 7,673、输出 713 Token、39,267 ms。验收时曾因历史记录加载竞态额外重复调用一次（输入 7,673、输出 643 Token）；按钮加载状态已修复，随后只读浏览器复测通过。

## 范围与遗留

P4 的本地核心验收针对当前支持的表达式和论文布局通过。复杂 PDF 公式的自动视觉转录、矩阵转置和张量维度的完整形式化证明、任意实验表格的语义解析、外部实现代码与训练峰值内存核查仍未覆盖。遇到这些情形，系统应保持未定或待澄清；不能把工具反例或模型反证直接当作论文事实错误。正式意见的纳入规则和中英文导出属于 P5。
