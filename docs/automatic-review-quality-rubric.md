# 独立审稿质量与性能联合验收（候选规范 1.0）

适用范围：普通用户自动审稿。本文不替换、不修改历史 P5 Manifest、盲测参考或科学裁定规则。Fake SDK 只验证工程，不构成学术质量证据。

## 固定样本与封存

`docs/examples/auto-review/papers.json` 固定 6 页、14 页两篇开发回归论文的身份和 SHA-256。这两篇已经参与调试，不能称为独立留出集。真实盲评另需至少一篇未参与调试的 6–15 页论文，在首次执行前冻结 PDF、人工参考意见的来源及哈希。参考意见在报告封存前不进入模型输入；非专家参考不能称为专家金标准。历史 SARDet/SAM 冻结资产保持不变，不依据系统输出修改参考问题。

优化前、后使用相同 PDF、审稿要求、模型配置、预算口径和外部材料政策。记录 Commit、Tree、Prompt 哈希、产物哈希、完整自动谱系和修复次数；一次失败及未知Usage也必须计入，不能只挑最快成功样本。真实测试与本地 Fake 输出分目录保存。

报告使用随机 A/B 编码，评审者不看版本、速度和费用。至少一位具备相关领域背景的独立审稿人逐条回查 PDF；第二位评审复核重大分歧。Codex 辅助评阅和模型自评只能作为补充，不能单独给出学术质量 PASS。自动生成、reviewer_added 和人工编辑意见分开统计，人工补充不能计为自动能力。

## 逐条意见评价表

|意见ID及来源|PDF页/对象/原文事实|原文是否已经回答|反证与限制|重要性及可操作性|分类|处置|
|---|---|---|---|---|---|---|
|填写（auto/reviewer_added/edited）|原始PDF定位，不能只引用模型摘要|是/否/部分/无法核实|列出作者解释与未核验条件|具体科学影响和作者可执行动作|A/B/C/D/E|保留/收窄/合并/删除/待核验|

分类：A=有直接来源支持的重要实质问题；B=有依据且值得作者澄清的问题；C=合理但次要的复现性/表述建议；D=证据不足、泛泛或不可操作的意见；E=原文已回答、错误归因、编造或不成立的指控。P3 的 inconclusive 不自动对应 D；专业措辞不自动对应 A/B。

## 报告级独立评分

每项 0–4 分：0=严重错误/缺失，1=明显不足，2=基本可用但需实质修改，3=专业且证据充分，4=深入、具体且经原文独立核实。无法评价填 NA 并解释，不能当满分；不允许为了凑数量产生问题。

|维度|评分（前/后）|必需核查证据|
|---|---|---|
|论文理解事实准确性| / |研究问题、贡献、方法、数据与结果逐项回查|
|创新性评价专业程度| / |正确区分作者贡献与已有方法，不凭空补文献|
|理论/方法/算法深度| / |假设、公式、机制及适用范围的实际论证|
|实验设计与结果分析| / |对比公平性、消融、统计和泛化，考虑发表语境|
|Major实质性| / |真正影响结论的问题，不把解析缺口当论文错误|
|Minor合理性| / |次要且具体，不重复Major，不追求固定数量|
|证据引用准确性| / |页码、表格/公式、数值、配置及反证对应|
|作者修改建议可操作性| / |能通过明确补充实验、分析或解释回应|
|错误批评/重复/幻觉控制| / |E类、重复和无来源数字逐条登记|
|不确定性及核验限制披露| / |P3原裁定、人工状态、外部代码/视觉核验限制|

硬阻断：编造关键证据/实验、错误指控足以改变核心评价、隐瞒未知费用、把AI核验说成人工确认、改写冻结P3裁定或丢失来源谱系。总分不能抵消硬阻断。建议验收门槛：无硬阻断，所有可评维度≥2，事实与证据两项≥3，优化后没有经独立评审确认的实质退化；未完成独立人工评价只能记“未验证”。保留原始分项、分歧和E类记录，不单报平均分。

## 性能验收与停止条件

记录上传起点、P1解析完成、预算确认启动、各阶段起止、草稿可读和导出可用时间。上传解析时间与用户确认等待单列；主要运行指标为确认启动→有效中文草稿，同时报告上传→报告（扣除用户等待）。每请求记录派发/结算时间、操作、Token、暂估费用、未知Usage和实测并发。SDK跨度包括网络及本地结算，不能说是供应商纯推理时间。

六维、P2-C关系/覆盖、P3反证/技术检查、P4一致性及双账仍必需。并发的已派发请求必须结算或保留未知；Unknown Usage后禁止新增派发，不重放。软件速率和费用规划不等于供应商硬上限，付费前需核实账号限额及并发许可。

5分钟为目标，不是SLA。每种页数组至少20次独立授权的真实任务后才汇报P50/P90；失败率、超预算、修复及未知Usage单列，不用零延迟或人为延迟Fake耗时推断真实速度。真实科学质量通过和真实性能通过分别判定，二者均需独立证据。
