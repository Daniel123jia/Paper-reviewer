# P6 本地集成与预部署检查（2026-11-03）

## 本阶段实现

- 可选单账号保护：未配置口令时维持本地工作方式；配置 `PAPER_REVIEW_ACCESS_TOKEN` 后，除登录和状态接口外，所有 `/api/` 路由均要求签名会话 Cookie。Cookie 为 HttpOnly、SameSite Strict，12 小时到期。登录页、退出登录、PDF.js 原页阅读和下载均通过同源请求工作。
- 显式预部署模式要求至少 32 字符访问口令及 Secure Cookie 标志；缺任一项，服务启动失败。部署仍需 HTTPS 反向代理与登录限速，本阶段没有执行公网部署。
- 服务启动时将先前处于 `queued` 或 `running` 的审稿分析和深化复核记录标为失败并写明重启中断，允许重新运行，不再无限显示“运行中”。
- 新增 `/api/usage/summary` 和页面“模型用量”，合并聊天、审稿和英文草稿调用，显示模型、输入输出 Token、耗时、失败次数、已知费用和费用未知次数。没有配置单价时显示“未配置”。
- 新增 `scripts/p6_smoke.py`，用真实论文执行上传、重复上传快照复用、检索、证据读取、原 PDF 校验、离线报告 PDF 导出和并发读取，不提交论文给模型。

## 实测结果

样例为 5 页《Self-Attention with Relative Position Representations》。在新的本地受保护数据目录中：

| 操作 | 本机单次观测 |
|---|---:|
| 首次上传与解析 | 108.0 ms |
| 同一 PDF 重复上传并复用快照 | 31.5 ms |
| 检索 `relative position`，16 条命中 | 96.5 ms |
| 原始 PDF 获取与 SHA-256 校验 | 11.9 ms |
| 创建离线报告并导出一页 PDF | 2,564.5 ms |
| 16 个并发检索/PDF 读取 | 828.9 ms |

烟测调用模型 0 次。性能数字只代表本机此论文和当前负载，不是服务器容量保证。另有 16 个同时上传同一有效 PDF 的后端测试，全部成功且只留下一个文档、一份解析快照和完整原件。

## 遗留与部署边界

- 当前认证是单账号模式，不支持多人角色或租户隔离。实际公网部署前仍需 HTTPS 反向代理、登录限速、备份恢复演练以及单进程工作模式检查；本轮只在 `127.0.0.1` 验证。
- SQLite 并发验证针对本机短时请求，尚未进行长时间压力测试。启动恢复逻辑适合单进程服务，多进程实例需要任务租约协调。
- P5 的 Microsoft Word 原生逐页目测、复杂排版及多篇不同论文的审稿准确率仍待扩展；未确认的数学疑点继续只能作为待澄清问题。
- 没有部署到服务器，也没有集成到原科研网站。用户本地满意后再决定部署。
