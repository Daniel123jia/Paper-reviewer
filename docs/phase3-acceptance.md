# P3 审稿分析本地验收（2026-11-03）

## 实际实现

- 可创建一审、本人复审和新增审稿人任务。本人复审要求原稿、修订稿、作者回复；新增审稿人二审要求原稿与修订稿。材料通过不可变 PDF 文档 ID 关联，任务与运行结果保存在 SQLite。
- 审稿分析从每份材料的不同页面抽样原文，合计最多 30 个证据块；短作者回复也会保留抽样配额。第一次模型调用提出最多三条候选问题，第二次独立调用逐条检查原文是否支持判断、寻找反证与替代解释。
- 每条结果保存 Evidence ID、材料角色、页码、证据等级、验证状态、支持关系说明和反证说明。无效 Evidence ID 会被排除；有原文位置与 AI 复核说明的疑点仍标为“待独立验证”，不会自动写成已证实错误。
- 网页显示任务状态、候选问题、模型 Token 与未知费用；点击证据会切换到对应 PDF 页，并把高亮滚动到可见区域。刷新后任务和结果仍可读取。

## 真实运行结果

使用本机真实五页论文 `Self-Attention with Relative Position Representations.pdf`，一审任务 `ec2b53cf04894f47870d545112c5d0e0` 完成。模型提出一条“整体自注意力空间复杂度的统计范围需要澄清”的候选问题；独立复核指出原文谈的是相对位置表示的存储，不能据此断言复杂度公式错误。结果引用第 3 页三个可解析的 Evidence ID，并保存了支持关系与反证说明。该问题的状态为 `needs_independent_verification`。

本轮两次真实中转站模型调用：提议阶段输入 7,261、输出 357 Token，耗时 17,322 ms；反证阶段输入 7,497、输出 410 Token，耗时 12,958 ms。费用仍为未知，因为没有中转站的可信计价配置。每次重新分析会再次消耗 Token。

## 边界与下一阶段

- P3 是抽样候选问题筛查，最多读取 30 个证据块，可能漏掉正文、附录和图表中的重要内容；不能称为完整深度审稿。
- 重新分析会保存新的运行记录，但目前网页只展示最新一次结果；旧运行的浏览与比较需要在后续阶段补上。
- 二审的材料选择、保存和角色传递已经测试；尚无真实“原稿＋修订稿＋作者回复”成套材料供语义质量验收。
- 第二次模型调用是独立反证步骤，但模型判断仍可能错误。P4 需要用 SymPy、NumPy 和可复跑的推导、实验核查来确认或排除技术疑点。
- 当前没有正式审稿意见、DOCX/PDF/Markdown 导出，也没有服务器鉴权。服务器部署仍需等本地完成 P4–P6 并由用户验收。
