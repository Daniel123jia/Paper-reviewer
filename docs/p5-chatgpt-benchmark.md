# P5 ChatGPT webpage benchmark protocol

Status: **pending**

No independent ChatGPT webpage deep-review output has been supplied for the five frozen papers. EtPaper results will not be disclosed to ChatGPT before a future reference run, and this repository will not invent, reconstruct, or substitute a reference output.

When supplied, each benchmark record must include the exact PDF SHA-256, ChatGPT model and mode as shown by the product, prompt, web/tool access, execution date, complete original output, and any follow-up edits. The evaluator will freeze that output before matching it to EtPaper issues.

Comparison will use the same issue-level A/B/C/D/E rubric as EtPaper: factual accuracy, evidence support, scientific importance, specificity/actionability, non-redundancy, uncertainty calibration, and professional expression. Matching is semantic, not lexical. Disagreements are resolved by PDF evidence and independent human judgment; ChatGPT is not presumed correct.

Until those independent outputs exist:

- benchmark competitiveness remains `pending`;
- no parity, superiority, or equivalence claim is allowed;
- EtPaper’s Evidence IDs and workflow features may be described as engineering properties, not proof of better scientific judgment.
