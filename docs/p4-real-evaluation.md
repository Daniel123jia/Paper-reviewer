# P4 三篇公开论文真实评测

本评测在本地完整冻结来源链上完成：沿用已验收的 P2-A/P2-B 数据库、P2-C 结果、P3.1 `recorded_model_replay` 结果与对应公开 PDF。P4 重新调用真实写作模型生成报告；没有重新执行 P1、P2-A、P2-B、P2-C 或 P3。P3 的历史响应重放在 P4 来源标识中明确记录，不能理解为 P4 新完成的独立科学核验。公开样例不含密钥、完整模型请求、原始模型响应或私有数据目录。

## 准入与实际报告

| 论文 | P3 原始问题 | 内部报告主题 | 默认作者草稿 | 状态 |
|---|---:|---:|---:|---|

| DistilBERT 2019 | 9 | 8 | 0 条，中英双语均明确说明无自动准入意见 | Table 2 疑点为 `requires_human_review`；无人工证据确认 |
| fastText 2016 | 9 | 9 | 1 条完整训练成本与单轮速度比较澄清，中英双语 | `concern_narrowed`、限定性自动草稿资格，尚未获审稿人批准 |

DistilBERT 的两个仅 MLM 匹配基线疑点共享 Claim 与具体技术核验对象，报告层合成一个主题，但保留两个独立 P3 Issue ID、原文依据和待核验事项。其余问题保持独立。所有自动意见仍为 `reviewer_approval_status=pending`。没有任何用户审稿人的最终批准，公开样例和导出均带 Draft 标识。

P4.1 使用同一冻结来源做了确定性重放，没有发起新模型调用：Shaw、DistilBERT、fastText 仍分别为 6、8、9 个内部报告主题，作者准入仍为 1/0/1。DistilBERT 的 MLM-only 两项问题同时指向匹配的 teacher-initialized student + MLM-only 基线及其实验核验需求，新规则下仍有充分理由合组。共享 Claim 与技术短语、但分别询问泛化与内存复杂度的合成反例保持为两组。

外部依赖重放显示：DistilBERT 三项依赖原始代码/脚本的内部核验问题为 `critical_unresolved`；Shaw 和 fastText 各一项外部待办与当前最终科学提问不构成关键依赖，为 `noncritical_unresolved`。这些状态均保留在内部证据包，不伪装成 P3 已完成外部核验。

三篇论文的中文、英文内部报告和作者意见草稿分别见 [Shaw](examples/p4-shaw2018/)、[DistilBERT](examples/p4-distilbert2019/) 和 [fastText](examples/p4-fasttext2016/)；每个目录还提供报告规划、准入与来源映射、逐条工程质量审阅及脱敏调用和导出检查记录。质量审阅由 Codex 逐条阅读生成稿和冻结材料完成，用于 ChatGPT 独立验收；它不冒充真人审稿人批准或完整的原文视觉核验。

## 学术质量检查

- **准确性与限定范围**：Shaw 作者稿没有否认已有 Key/Value 消融，也没有把结构上的未见长度适用性当作已证明的翻译性能外推。fastText 作者稿承认论文已披露单轮计时、五轮训练、硬件和线程条件。DistilBERT 的两处 SQuAD 数值仅在内部报告中作为待澄清差异；未宣称作者错误。
- **具体性与科学价值**：两项作者稿分别定位到相对距离裁剪与长度外推解释，以及速度倍数的比较对象、分母和完整训练口径；都提出作者可直接回应的条件。内部报告对来源不足的问题保留检查任务，没有强制填充 Major/Minor。
- **非冗余性**：DistilBERT 相关消融疑点在报告表达层合组。相近但核验对象不同的训练配置、阶段蒸馏及性能口径保持分开。作者稿各仅一项或零项，不堆砌候选问题。
- **证据与风险**：每条 P4 意见都有 P3 Issue ID；公开映射包含 Source Ref、PDF 页码、原始 Evidence ID 与核验状态。未验证表格和公式仍标为待复核；外部文献未取得时没有写为已证实事实。
- **专业表达与双语**：中文和英文分别基于同一冻结事实包生成，保留相同问题成员、来源、数值和审查范围。英文按审稿习惯提出澄清请求；中文避免确定性指责。确定性校验无法证明所有自然语言含义完全一致，最终仍需审稿人检查。

逐问题的具体评价见三个 `quality_review.md`，包括每条问题的原文依据、价值及未解决限制。ChatGPT 网页端深度审稿质量对标仍为 **pending**；本阶段没有参考结果，不宣称达到同等水平。

## DistilBERT Table 2 人工复核门槛

原 PDF 第 3 页 Table 2 的视觉版面可看到 DistilBERT (D) 一行对应 79.1 EM、86.9 F1；后续正文摘录另有 70.4 EM、79.8 F1。该工程视觉观察不作为系统中的真人 `EvidenceReviewRecord`。P3.1 仍标为 `visual_check_required` 与 `requires_human_review`，P4 默认作者稿为空。实际 API 测试证明无记录时 `approve_for_draft` 返回 409；合成表格回归证明需记录页码、行列、指标顺序、数值和未确认配置后，才能在不改动 P3 判定的情况下做限定性采纳。两处实验设置是否相同仍待审稿人确认。

## 导出与回归

## 模型调用与剩余风险

`model_usage.json` 分别列出所有 P4 调用尝试、请求/实际模型、Prompt 版本、已知 Token、耗时、状态及错误类别。历史失败和被规则拒绝的尝试也计入总调用，失败调用的未知 Token 不按零成本处理。原始请求与完整响应保存在受限本地评测目录或不保存，不提交公开仓库。

| 论文 | 全部 P4 调用尝试 | 成功 / 连接失败 | 已知输入 / 输出 Token | 调用耗时合计 |
|---|---:|---:|---:|---:|
| Shaw | 61 | 56 / 5 | 546,527 / 29,164 | 1,318.3 秒 |
| DistilBERT | 54 | 50 / 4 | 489,659 / 25,929 | 1,101.7 秒 |
| fastText | 68 | 63 / 5 | 621,098 / 30,601 | 1,231.6 秒 |

以上包含开发期间被 Schema/一致性规则拒绝的尝试、保存的历史草稿及最终草稿；它不是单次生产运行的成本估算。14 次连接失败的 Token 未知，表中 Token 为已知下界。最终保存的 12 份草稿合计对应 102 次已记录调用，其中两份 DistilBERT 空作者草稿不触发模型。实际请求模型为 `gpt-6.1-sol`，每次实际返回模型与 Prompt 版本见样例中的脱敏调用记录；没有把 P3.1 历史重放计入 P4 模型调用。

剩余风险：人工批准与独立科学证据复核仍是不同动作；外部核验记录仍由审稿人对材料身份、版本与核验范围负责，P4 不自动下载或判定外部文献真实性。未经审稿人确认的报告不能作为最终正式意见。自然语言的事实一致性只能做部分确定性约束。三篇论文中的 PDF 表格、公式、外部文献与实验配置疑点仍可能影响正式审稿判断。生产环境需补齐论文原文和诊断数据的访问权限、保留期限与密钥配置。P5 的全新真实模型全链路质量回归及 ChatGPT 网页端对标均未在本阶段完成。
