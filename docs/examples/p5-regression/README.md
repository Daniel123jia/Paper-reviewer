# P5 historical regression artifacts

This directory contains sanitized P5 summaries for Shaw 2018, DistilBERT 2019, and fastText 2016. It must not contain source PDFs, private databases, raw prompts, raw model responses, API keys, or private endpoint details.

The three `*-scientific-evaluation.json` files are non-expert manual checks of one sentinel issue per historical paper. Their source results are explicitly labelled `recorded_model_replay`; they are not fresh P5 runs or complete-paper quality scores.
