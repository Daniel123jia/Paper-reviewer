# 面向作者的审稿意见

## 总体评价

作者提出 fastText，将秩受限线性模型、特征嵌入平均、层次 softmax 与可选的 n-gram 特征结合，用于高效文本分类，并通过情感分类和大输出空间的标签预测评估准确率与计算效率。本文对实用文本分类方法的效率具有参考价值。当前需要澄清的是情感分类加速结论的比较口径：应明确单轮训练耗时与达到所报告准确率所需的完整训练耗时之间的关系，以便读者准确理解效率优势的适用范围。

## 需要澄清的问题

### 1. 澄清情感分类加速倍数的计算依据与训练范围

情感分类的训练时间表题注明比较的是单轮训练耗时，结果段则说明作者使用五轮 fastText 训练获得所报告的准确率。训练时间段也已披露卷积基线使用 GPU、fastText 使用 20 线程 CPU，并说明实现更新可能影响基线速度。这些信息有助于理解比较条件，但“至少 15,000 倍加速”究竟对应哪个数据集、哪个基线及模型配置，以及该倍数采用单轮还是完整训练耗时，仍需明确。此区别直接影响读者能否将该结论理解为达到所报告准确率所需的时间优势。请在该加速表述附近列明对应的数据集、比较模型及配置、双方耗时和计算式，并说明准确率与计时结果是否来自相同配置。若作者希望将该结论用于完整训练比较，请补充基线的训练轮数或停止条件，并计入 fastText 的五轮训练，给出相应的完整训练耗时比；若现有记录仅支持单轮比较，请将分类加速结论明确限定为已披露硬件、线程数和实现条件下的单轮计时结果。
