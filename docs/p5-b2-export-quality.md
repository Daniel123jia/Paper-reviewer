# P5-B2.1 DOCX/PDF 导出质量

## 变更边界

本轮只改动确定性导出层。Markdown 正文、P1—P3、P4 科学裁定、Prompt、人工审批、DRAFT/正式导出权限和历史数据库均不变；没有模型请求。

## PDF 分页规则

- 短表格继续整体保留，避免一两行表格无意义跨页。
- 行数不少于 6 或文本量不少于 900 字符的长技术表格允许在行边界跨页。
- 表头在跨页后重复，单个表格行不拆页。
- 标题与紧随其后的首段、首个列表或表格保持相邻，避免标题孤立；不再把多个完整附录小节强制绑定在同一页。
- 长附录、长列表和长表格允许自然跨页，报告 PDF 使用 20mm 常规页边距改善页面利用率；字号和行距保持不变。
- 长 Issue ID 和 Evidence ID 允许在单元格内断行，不改变字符串内容。
- 正文字号和行距未因本修复而缩小。

## DOCX 字体和表格规则

- 中文样式与具体中文文本运行都包含 `w:eastAsia`、`w:hint=eastAsia` 和 `w:lang=zh-CN`。
- 具体中英文混合运行同时声明通用 Unicode 兼容字体，避免 LibreOffice 忽略只存在于 `w:eastAsia` 的字体信息，并允许阅读器使用本机中文字体替代。
- 字体表登记 `Source Han Sans SC` 及中文别名，并保留 Office `minorEastAsia` 主题回退；不嵌入或分发字体文件。
- 表头行设置为跨页重复，所有数据行设置为行内不可拆分；表格仍可在行间跨页并保持可编辑。
- Heading 1—3 使用样式级 `keep_with_next` 保持标题与首段相邻；普通正文不设置连续 `keep_with_next`，避免多个附录小节组成不可分页的大块。

## 字体部署说明

DOCX 不携带字体文件。目标阅读器应安装 `Source Han Sans SC`（思源黑体）或具有可用的中文替代字体。LibreOffice 的无界面运行环境必须能够通过 Fontconfig 发现该字体；若运行包装器隔离了系统字体，即使 DOCX 文本和字体元数据完整，转换结果仍可能出现方框或缺字。

Microsoft Word/WPS 的最终兼容性必须在对应真实阅读器中人工打开确认。LibreOffice 辅助渲染不能替代该结论。
