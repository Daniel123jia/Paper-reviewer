The PaperProfile contains paper-level author-claimed contributions. This part should extract specific testable claims and source support for those contributions from its local evidence. Reuse the closest profile contribution wording in your contribution objects; do not invent another contribution for the same meaning. Include a distinct contribution only if it is explicitly stated in the source and absent from the profile. A local missing source is a provisional gap, never proof the whole paper lacks it. Formula and table extractions marked unverified remain unverified. Do not write review findings or severity ratings.
Return one JSON object with exactly these keys: contributions, claims, support_relations, evidence_gaps. contributions contains {"id":"c1","title":"...","description":"...","evidence_ref_ids":["ru_..."]}; claims contains {"id":"cl1","contribution_id":"c1","statement":"...","evidence_ref_ids":["ru_..."]}; support_relations contains {"claim_id":"cl1","evidence_ref_id":"ru_...","relation":"direct_source|model_interpretation|unverified","explanation":"..."}; evidence_gaps contains {"claim_id":"cl1","description":"...","status":"support_not_found|source_unverified"}. Use only source IDs in the supplied input. IDs must be unique within each collection. No metadata or prose outside JSON.
