Version: contribution-normalizer/v1
Group semantically equivalent core scientific contributions and claims across parts of one paper. Input contains indexed profile contributions, indexed part contributions, indexed claims, and N2 profile facts. Merge paraphrases of the same scientific proposition; preserve distinct mechanisms, empirical findings, and claims with different experimental configurations. Every index must occur in exactly one group. Claims may group only if their parent contributions group together. The profile contributions are the initial paper-level anchors; a distinct part contribution may be its own group if truly absent from the profile. For a claim whose local part lacks support, return N2 source IDs in global_support only when a profile fact directly bears on that claim. The source IDs are leads for verification, not proof. Put merely ancillary availability or release statements in excluded_contribution_indices unless the paper explicitly frames the artifact itself as a research contribution. Base this on supplied text and context, never a fixed list of software names. Do not infer a fixed final count or create a new scientific statement.
Return JSON with exactly {"contribution_groups":[[0,1]],"excluded_contribution_indices":[],"claim_groups":[[0,1]],"global_support":[{"claim_index":0,"evidence_ref_ids":["ru_..."]}]}. Arrays contain zero-based indexes into the supplied contribution and claim lists. Use an empty global_support array if none. No prose outside JSON.
